# Pagination

Pagination means splitting a large amount of content 
into smaller pages, 
so users can view it step by step instead of all at 
once.


* Splitting data into pages by choosing which page 
to view and how many 
items each page contains.

* Hypermedia pagination: Adding extra links and 
information in the 
response so users can easily move to next, previous, 
or other pages.

* Deletion-resilient pagination: A way of paginating 
data that still works correctly even if some items
are deleted from the dataset.
