# NoSQL

## NoSQL is a non-relational approach to database management 
designed to handle the performance, scalability, and 
flexibility requirements of modern, data-intensive 
applications.

- NoSQL: database that doesn’t use tables, stores flexible data formats

- SQL vs NoSQL: SQL = structured tables, NoSQL = flexible document/collection style

- ACID: rules that guarantee safe and reliable database transactions

- Document storage: storing data as JSON-like documents

- NoSQL types: document, key-value, column, graph

- Benefits of NoSQL: scalable, fast, handles large/unstructured data well

- Query NoSQL: getting data using commands like find()

- Insert data: adding new records into a collection

- Update data: modifying existing records

- Delete data: removing records from a collection

- MongoDB: NoSQL database that stores data in JSON-like documents

- Aggregation: processing data to calculate/group results

- Mongo Shell: command-line tool to run MongoDB commands

- MongoDB + Python: using PyMongo to connect and run database operations

- CRUD operations: Create, Read, Update, Delete data actions
