## How to define a Class
 - A class is a blueprint used to create objects with shared structure and behavior

## How to add methods to a class?
 - By writing functions inside the class to define behavior


## Why and how to add a static method to a class?
To create a function used by the class itself, not its objects

## How to extend a class from another?
By creating a class that inherits from another class

## What is Metaprogramming?
Writing code that can modify or control other code

## What are Symbols?
Unique identifiers used as object property keys
